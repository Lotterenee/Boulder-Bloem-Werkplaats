# Woordenlijst (domeinbegrippen)

## WAS 2023 - speelaanleiding vs. speeltoestel
- **Warenwetbesluit attractie- en speeltoestellen 2023 (WAS 2023):** sinds 1 juli 2023 geldende
  regelgeving voor veiligheid van speeltoestellen op openbare/semi-openbare terreinen (o.a.
  schoolpleinen, kinderopvang).
- **Speelaanleiding zonder vaste constructie** (bv. hut van losse takken, wilgentenenhut):
  **valt NIET onder WAS** → geen keuring.
- **Speeltoestel / natuurlijke speelaanleiding mét vaste constructie:** **valt WEL onder WAS**
  → keuringsplichtig; eerste keuring (ingebruiknamekeuring) + herkeuringen door een
  **AKI** (Aangewezen Keuringsinstelling, bv. TÜV, Keurmerkinstituut); RAS-nummer in het register.
- **Gevolg in De Kas:** `Element.soort` telt in de studio speelaanleidingen vs. keuringsplichtige
  toestellen; de offerte legt de rol vast (leverancier keurt toestellen; opdrachtgever beheert
  na oplevering).
- **Let op:** particuliere tuin = speeltoestel geldt als "speelgoed" (buiten WAS).

## De zeven projectfasen
kennismaking → locatieanalyse → samen ontwerpen → schetsontwerp → definitief ontwerp →
aanleg → oplevering & beheer.

## Subsidie-statussen (aanvraag)
scan → kansrijk → in voorbereiding → ingediend → toegekend/afgewezen → verantwoording → afgerond.

## Overige
- **Valruimte:** vrije zone rond een toestel waarbinnen bij val niets mag staan
  (per element `valruimteM`).
- **Inheems-percentage:** aandeel inheemse planten; vaak subsidie-eis (bv. ≥50% natuurlijk/inheems).
- **Nulmeting / jaartelling:** biodiversiteitsmeting bij start resp. jaarlijkse herhaling.
- **Laatst gecheckt:** datum waarop een subsidieregeling handmatig geverifieerd is
  (kleurcode: groen <3 mnd, oranje ouder).
